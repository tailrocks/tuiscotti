# R01 PR body: U02

Target title: `Add an owned terminal snapshot API`
Target branch: `goal/u02-owned-snapshot` (base: upstream `main` at `f2760592ed00e90436f8c3bae124dab712eaecf8`)

## Problem

`Engine::frame()` returns an unowned `LiveFrame` for the monitor only. Offline producers and visual tests have no public owned snapshot: no validated constructor, no capture scopes, no canonical state contract.

```rust
// crates/tui-test/src/engine.rs at f276059
pub fn frame(&self) -> Option<LiveFrame>
```

## Change

New public owned `TerminalSnapshot` in `crates/tui-test/src/snapshot.rs` with private fields and read-only accessors: logical columns and rows; row-major cells and continuation cells; grapheme strings and cell widths; default, indexed, and RGB color references; all 256 resolved palette entries and foreground, background, and cursor defaults; cell attributes and underline details; hyperlink URI and available identity; cursor coordinates, visibility, shape, color, and available blink intent (live capture records unknown blink as `None`, never `false`); window title; capture scope and viewport origin. Capture scopes: viewport, active-screen, full-history with `u32` coordinates and checked casts. New `Session::capture_snapshot` / `Engine::capture_snapshot` (plus `_with` highlight options) capture related fields under one terminal-state lock with resolved colors only from `Emulator::colors()`. Validated offline constructor `TerminalSnapshot::try_new` with shared `TryFrom`/Serde validation. Observation metadata stays out of canonical equality and hashes.

## Compatibility

Additive only. `State`, `Cells`, `PackedScreen`, `LiveFrame`, and the monitor highlighting path keep their recorded behavior; default capture uses raw visual data. No new required `Emulator` methods. No FFI or binding changes (`tui-test-bindgen -- --check` passes). No MSRV change. No new dependencies.

## Limits

Live capture cannot report cursor-blink intent: no backend reports it and the trait has no such required method, so live snapshots record unknown rather than a default. Full-history coordinates need `u32`; narrow `u16` emulator interfaces use checked conversions.

## Scope

The engineering requirement is a public owned snapshot for live capture and offline construction through one validated model. Downstream approval policy stays out of this PR.
