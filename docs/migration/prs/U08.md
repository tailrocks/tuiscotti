# R01 PR body: U08

Target title: `Add explicit child launch settings`
Target branch: `goal/u08-launch-options` (base: upstream `main` at `f2760592ed00e90436f8c3bae124dab712eaecf8`)

## Problem

Child processes launch from `RunOptions` display strings with inherited-process semantics baked in. There is no way to clear the environment, remove named variables, override values, or pass native arguments without shell interpolation.

## Change

New private-field `LaunchOptions` in `crates/tui-test/src/launch.rs`:

```rust
pub fn spawn_with(&self, resolved: &ResolvedLaunch) -> ... // Session + Engine entry points
```

Program, arguments, environment keys and values, and the working directory are native strings (`OsString`/paths), never assembled into a shell command. Environment modes are inherited or cleared; removals, mandatory tui-test terminal defaults (`TERM=xterm-256color`, re-applied after removals), and explicit caller overrides apply in that order. The full child environment resolves before the first spawn and the resolved values are kept for restart — the changed parent environment is never re-read. The command-builder environment is cleared before filling; transport defaults that `portable-pty` adds (Unix `SHELL` forcing) are recorded, and no empty environment is promised. Invalid keys, NUL values, and invalid native arguments return typed `Usage` errors. `RunOptions` and `OpenOptions` gain no fields; recorded launch methods and defaults are unchanged.

## Compatibility

Additive only. `OpenOptions`, `RunOptions`, `Operation`, and exhaustive enums are unchanged. No FFI or binding changes. Rust-only. No MSRV change. No new dependencies.

## Limits

A cleared Unix child always contains `SHELL` (transport-forced) plus the resolved values; an exactly empty environment is not promised. `Session::spawn_with` duplicates the recorded reader and watcher setup (~140 lines) to keep `open()` byte-identical; a shared helper is future work.

## Scope

The engineering requirement is reproducible child execution with explicit environment and argument control. Raw input and checked input modes are separate changes.
