# R01 PR body: U03

Target title: `Add public rendering for offline terminal snapshots`
Target branch: `goal/u03-offline-rendering` (parent: U02 branch `goal/u02-owned-snapshot`, draft PR [#278](https://github.com/microsoft/tui-test/pull/278))

## Problem

Live screenshots and recordings render through internal paths that an offline caller cannot reach. A saved or synthetic `TerminalSnapshot` has no public SVG or PNG rendering:

```rust
// no public offline render function exists at f276059
```

## Change

New public functions over the owned snapshot in `crates/tui-test/src/render/offline.rs`:

```rust
pub fn render_snapshot_svg(snapshot: &TerminalSnapshot, options: &SnapshotRenderOptions) -> Result<RenderedSvg, RenderError>
pub fn render_snapshot_png(snapshot: &TerminalSnapshot, options: &SnapshotRenderOptions) -> Result<RenderedPng, RenderError>
```

Both go through one new private resolved-layout type shared with the live screenshot and recording paths (small additive edits to `svg.rs`, `raster.rs`, `encode.rs`; live behavior and signatures unchanged). `SnapshotRenderOptions` carries explicit cell metrics (cell width and height, font size, text baseline offset, scale), canvas and content padding, title-bar visibility and controls, shadow, border width and radius, with validation (nonfinite values, bad dimensions, and out-of-cell baselines rejected; checked image-size arithmetic). A 3-column, 2-row grid with 10-by-20 cells gives a 30-by-40 image with no decoration. Hidden or clipped cursors stay hidden. Raster code stays behind `recording-raster`; SVG builds without it. Public `Style` is unchanged; layout defaults are inherited from `Style::default()`.

## Compatibility

Additive only. Live `render_svg`, `GridRenderer`, and `encode_png` behavior unchanged; `Style` fields and methods unchanged. Rust-only, no FFI or binding changes (`tui-test-bindgen -- --check` passes). No MSRV change. No new dependencies.

## Limits

SVG text uses viewer fonts, so SVG has no pixel-identity promise; decoded PNG pixels are the strict gate. The transparent canvas and cursor-drawn flag are recorded in the render evidence. Pinned fonts arrive in a later change; options currently resolve fonts from live `Style` defaults.

## Scope

The engineering requirement is public offline rendering for saved and synthetic terminal state through the shared renderer. Font pinning and grapheme shaping stay out of this PR.
