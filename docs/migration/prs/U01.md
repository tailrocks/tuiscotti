# R01 PR body: U01

Target title: `Add an explicit read-only snapshot policy`
Target branch: `goal/u01-strict-snapshots` (base: upstream `main` at `f2760592ed00e90436f8c3bae124dab712eaecf8`)

## Problem

`assert::snapshot::compare()` takes `update: bool`. When `update` is false it still creates a missing baseline file on disk and returns `Written`:

```rust
// crates/tui-test/src/assert/snapshot.rs at f276059
pub fn compare(base: &Path, name: &str, content: &str, update: bool) -> std::io::Result<SnapshotStatus>
```

A caller that only wants to check state against a baseline cannot express "never write". A missing baseline is indistinguishable from a policy accident.

## Change

New explicit write policy in `crates/tui-test/src/assert/snapshot.rs`:

```rust
pub enum SnapshotPolicy { CheckOnly, CreateMissing, Replace }
pub enum PolicyOutcome { Equal, Missing, Different, Created, Replaced }

pub fn compare_with_policy(
    base: &Path,
    name: &str,
    content: &str,
    policy: SnapshotPolicy,
) -> std::io::Result<PolicyOutcome>
```

`CheckOnly` is the default and writes nothing, not even a directory. `CreateMissing` writes through a same-directory temp file plus `hard_link` (create-new semantics; a concurrent winner is re-compared, never replaced). `Replace` writes through temp file plus atomic rename. Equal content returns `Equal` without a write under all policies. `compare()` keeps its signature and behavior as a compatibility wrapper (`update` maps to `Replace`, otherwise `CreateMissing`).

## Limits

- `CreateMissing` reports a concurrent winner through re-comparison; it never merges contents.
- A process crash between temp-file creation and cleanup can leave hidden `.<stem>.new-*` files in `__snapshots__`; they never affect comparison.
- No candidate approval: approval policy stays downstream per the migration design.

## Scope

The engineering requirement is a strict read-only snapshot policy in tui-test so visual tests can compare baselines without accidental baseline creation. Downstream candidate approval stays out of this PR.
